The AWS Free plan was chosen for this project to ensure that the credit card is never billed,
at the cost that it closes after six months.
If the need arises later the plan can be upgraded to a paid tier.
An IAM user with access key was used because this is a single-account personal sandbox and the Free
plan minimizes the blast radius if the key is leaked. Therefore, an IAM Identity Center is not
needed for this project.
